{
1]
شريط أفقي في أعلى الصفحة
.navbar {
    display: flex;
    justify-content: center;
    gap: 15px;
    padding: 15px;
    background-color: #0249ad;
}

لماذا؟

display: flex يجعل الأزرار بجانب بعضها.
justify-content: center يضعها في المنتصف.
gap يضيف مسافة بينها.
padding يعطي الشريط مساحة داخلية.
2]
أزرار بارزة داخل الشريط
.navbar a {
    padding: 10px 20px;
    color: white;
    background-color: #0066cc;
    border-radius: 8px;
    text-decoration: none;
}

لماذا؟
يجعل كل رابط يبدو مثل زر، ويزيل الخط الموجود تحت الرابط.

3]
تغيير الزر عند مرور الماوس
.navbar a:hover {
    background-color: white;
    color: #0249ad;
}

لماذا؟
عندما يمر الماوس فوق الزر تتغير ألوانه.

4]إضافة ظل للأزرار
.navbar a {
    box-shadow: 0 4px 10px rgba(0, 0, 0, 0.3);
}

لماذا؟
يجعل الزر يبدو بارزًا عن الصفحة.

5]شريط علوي ثابت أثناء النزول
.navbar {
    position: fixed;
    top: 0;
    width: 100%;
}

لماذا؟
يبقى الشريط في أعلى الشاشة حتى عندما تنزل في الصفحة.

6]عل الشريط فوق جميع العناصر
.navbar {
    z-index: 1000;
}

ويفضل:

.navbar {
    position: fixed;
    z-index: 1000;
}

لماذا؟
z-index يجعل الشريط يظهر فوق العناصر الأخرى.

7]شريط أفقي + أزرار صفحات
<nav class="navbar">
    <a href="index.html">الصفحة الرئيسية</a>
    <a href="members.html">الأعضاء</a>
    <a href="about.html">من نحن</a>
    <a href="contact.html">اتصل بنا</a>
</nav>

ملاحظة مهمة للمسابقة:
href هو الذي يحدد الصفحة التي سينتقل إليها المستخدم.

8]
 زر له تأثير عند الضغط
button:active {
    transform: scale(0.95);
}

لماذا؟
يصغر الزر قليلًا أثناء الضغط عليه، فيعطي إحساسًا بأنه زر حقيقي.

9] زر بحواف دائرية
button {
    border-radius: 20px;
}

كلما زادت القيمة أصبحت الحواف أكثر استدارة.

10]إطار بارز حول صندوق كامل
.box {
    border: 2px solid #0249ad;
    border-radius: 15px;
    padding: 20px;
    box-shadow: 0 0 15px rgba(2, 73, 173, 0.4);
}

لماذا؟

border → الإطار.
border-radius → تدوير الحواف.
padding → مسافة داخل الصندوق.
box-shadow → يجعل الصندوق بارزًا.

11]وضع الصندوق في منتصف الصفحة
body {
    min-height: 100vh;
    display: flex;
    justify-content: center;
    align-items: center;
}



justify-content: center;
align-items: center;

تستخدم غالبًا لتوسيط العنصر أفقيًا وعموديًا مع display: flex.
12] جعل العناصر تحت بعضها
.container {
    display: flex;
    flex-direction: column;
}

لماذا؟
بدل أن تكون العناصر بجانب بعضها تصبح فوق بعضها.

13] جعل العناصر بجانب بعضها
.container {
    display: flex;
    flex-direction: row;
}

row هو الاتجاه الافتراضي لـ Flexbox.

14] توزيع الأزرار بالتساوي

    display: flex;
    justify-content: space-between;
}

}

لماذا؟
يضع مسافات متساوية حول وبين العناصر.

16] تغيير شكل المؤشر فوق الزر
button {
    cursor: pointer;
}

لماذا؟
يجعل مؤشر الماوس يظهر كيد عند المرور على الزر.
